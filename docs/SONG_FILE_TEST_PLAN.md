# ตรวจการสำรองและนำเข้าเพลง

ทดสอบด้วยเพลงที่สร้างเอง ห้ามนำเนื้อหาเพลงของผู้ใช้เข้ารีโป

1. ในหน้าแกะโน้ต สร้างเพลงชื่อไทย ตั้งคีย์ จังหวะและ tempo ใส่คอร์ดสองมือ โน้ตประจุด และโน้ตเริ่มที่ครึ่งหน่วย
2. กด **ส่งออกเพลง JSON** เลือกโฟลเดอร์บน Windows ตรวจว่าไฟล์ `.mimi.json` ถูกบันทึก แล้วนำเข้าไฟล์นั้น
3. ต้องได้เพลงใหม่ โดยเพลงเดิมอยู่ครบ ชื่อ คีย์ จังหวะ tempo จำนวนห้อง มือ pitch เวลาเริ่มและความยาวโน้ตตรงกัน เล่นฟังและฝึกแบบรอได้
4. ปิดเปิดแอปใหม่ ตรวจว่าโน้ตประจุดและเวลาเริ่มครึ่งหน่วยยังเหมือนเดิม
5. นำเข้าไฟล์เดิมสองครั้ง ต้องได้สองเพลงใหม่ ไม่ทับเพลงเก่า ลบเพลงสำเนาหนึ่งเพลงแล้วอีกเพลงต้องยังอยู่
6. ยกเลิกหน้าต่างเปิด/บันทึก ต้องไม่เพิ่มเพลง ไม่แจ้งว่าสำเร็จ และกดปุ่มซ้ำได้
7. ลอง JSON เสีย เวอร์ชันที่ไม่รองรับ pitch ผิดช่วง โน้ตเกินความยาวเพลง เกิน 20,000 โน้ต และไฟล์เกิน 5 MB ต้องแจ้งข้อผิดพลาดและไม่เปลี่ยนเพลงที่มีอยู่
8. ลองบันทึกไปตำแหน่งที่เขียนไม่ได้ ต้องแจ้งข้อผิดพลาดและเพลงเดิมยังอยู่
9. สลับเพลงขณะกำลังฟัง เสียงเดิมต้องหยุด ประวัติ undo/redo และช่วงวนต้องเริ่มใหม่ให้ตรงเพลงที่เลือก
10. ในเบราว์เซอร์ ตรวจการดาวน์โหลดและเลือกไฟล์ JSON อีกครั้ง (ไม่มีเสียง/MIDI ตามข้อจำกัดเดิม)

ไฟล์นี้สำรองเฉพาะโน้ตและการตั้งค่าเพลง ไม่รวมไฟล์เสียงหรือประวัติการฝึก การจัดเก็บหลักยังเป็น localStorage และยังต้องย้ายไป SQLite ตามสเปก

เทสต์อัตโนมัติอยู่ที่ `src/features/score/songFile.test.ts` ครอบคลุม round-trip ผ่านไฟล์และ storage, การสร้าง ID ใหม่, ขอบเขตข้อมูลและชื่อไฟล์ Windows
