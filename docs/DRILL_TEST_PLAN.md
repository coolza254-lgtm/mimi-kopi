# ตรวจโปรแกรมฝึก

## เทสต์อัตโนมัติ

- drills.test.ts: โจทย์ทดสอบคงที่ ซ้อมสลับลำดับ จำนวนมีขอบเขต ไม่ซ้ำติดกัน โน้ตผิดไม่ข้ามข้อ คอร์ดครบโดยไม่มีโน้ตเกิน ปล่อยก่อนข้อใหม่ พัก/กลับมา และ MIDI reset
- ประวัติ: บันทึกซ้ำไม่เพิ่มรอบ ข้อมูลเสียถูกปฏิเสธ เก็บไม่สำเร็จแจ้งได้ เก็บผิดในข้อที่ยังทำไม่จบ เทียบเฉพาะ reference เดียวกัน แยกจำลอง/จริงและรอบไม่จบ
- PracticePrograms.test.tsx: ไม่มีข้อความเฉลยในโจทย์อ่านโน้ต คีย์บนจอไม่มีชื่อ จบแล้วบันทึกครั้งเดียวใน StrictMode, Escape/พักระหว่าง feedback, storage ล้มเหลว, ซ่อนและคืนเมนู, นิ้วตรงคอร์ด, listener MIDI ครั้งเดียว/reset/cleanup

## ตรวจบน Windows จริง

1. เปิด Today → เริ่มรอบ หรือเมนูฝึกซ้อม ต้องเข้าโปรแกรมใหม่ บทเดิม 15 บทและประวัติยังอยู่
2. หาโน้ต: เลือกช่วง C4–G4 แล้วเพิ่ม C4–C5 / C3–C5 ตรวจช่วงเสียงกับเปียโน MIDI (C4 = MIDI 60)
3. อ่านบรรทัด: เห็นกุญแจและบรรทัด 5 เส้นเดียว กดคีย์ตอบ ไม่มีชื่อโน้ตหรือคีย์เฉลย ลอง C4 ที่เส้นเสริม E4 ที่เส้นล่าง และกุญแจฟาที่ช่วงต่ำ
4. คอร์ด: C = C4/E4/G4 นิ้ว 1/3/5, G/B = B3/D4/G4 นิ้ว 1/2/5, Am = A3/C4/E4 นิ้ว 1/2/4, F/A = A3/C4/F4 นิ้ว 1/2/5 ภาพนิ้วเป็นคำแนะนำ ไม่ใช่ผลตรวจนิ้ว
5. เลือก 12/24/48 และกำหนดเอง 12–120 ตรวจจำนวนจริง การกดผิดต้องคงข้อเดิม กดคอร์ดเพิ่มโน้ตผิดค้างไว้ต้องไม่ผ่าน
6. ตอบถูกมี feedback สั้น ๆ ต้องปล่อยคีย์ก่อนข้อใหม่ กด MIDI ระหว่าง feedback/พักไม่ให้คะแนนใหม่ ปุ่มพัก Escape และสลับหน้าต่างใช้ได้
7. ถอด MIDI กลางคอร์ด ต้องพักและล้างคีย์/นิ้วที่กดไป เมื่อกลับมาทำคอร์ดใหม่ครบจึงผ่าน
8. จบรอบแสดงถูกครั้งแรก จำนวนผิด และจุดที่ต้องทบทวน ตรงกับสิ่งที่เล่น จบก่อนครบติดป้ายไม่จบ ถ้ายังไม่ทำได้สักข้อจะไม่บันทึกเป็นรอบที่มีผล
9. ผลซ้อมไม่แสดงว่าเป็น benchmark เทียบรอบทดสอบต้องโจทย์/เวอร์ชัน/จำนวน/ช่วง/แหล่งอินพุตเดียวกัน ปิดแล้วเปิดใหม่ยังมีประวัติ จำกัดเก็บ 200 รอบล่าสุด
10. รอบจำลอง/จริงไม่ปนกัน รอบที่ใช้ทั้งสองแหล่งนับเป็นจำลอง กราฟต้องติดป้ายแหล่งข้อมูล ไม่เติมค่าเมื่อไม่มีผล
11. ตรวจธีมสว่าง/มืด ไทย/อังกฤษ/ญี่ปุ่น หน้าต่าง 1024×640 และขยายจอ โฟกัสไม่หลุดไปเมนูที่ซ่อน ลดการเคลื่อนไหวได้

## ขอบเขตการวัด

โหมดนี้รอจนกดถูก ไม่มีคะแนนจังหวะ ความเร็วอ่าน หรือการรับรองความคล่อง ใช้ความถูกครั้งแรกและจุดที่ผิดช่วยวางแผนซ้อม การอ่านคล่องในเพลงจริงยังต้องฝึกกับท่อนเพลงและประเมินภายหลัง โจทย์ทดสอบคงที่ไม่ใช่ข้อสอบอ่านโน้ตใหม่ครั้งแรก
