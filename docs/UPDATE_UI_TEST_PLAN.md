# แผนตรวจหน้าอัปเดตในแอป

หน้าจอนี้ปรากฏเมื่อกด **ตั้งค่า → ตรวจหาอัปเดต → อัปเดตแล้วเปิดใหม่** ในแอปเดสก์ท็อป ต้องมี Release รุ่นใหม่ที่ลงนามถูกต้องตาม `RELEASING.md` พรีวิวหรือเทสต์ที่ใช้ข้อมูลจำลองไม่ใช่หลักฐานว่าติดตั้งจริงสำเร็จ

## อัตโนมัติ

- `src/lib/updates.test.ts`: เปอร์เซ็นต์คำนวณจากไบต์จริง ขนาดไม่ทราบหรือข้อมูลไม่ถูกต้องต้องไม่สร้างตัวเลขสมมติ ดาวน์โหลดครบ 100% ยังไม่ถือว่าติดตั้งจบ รอ event Finished ก่อนเปลี่ยนขั้น และไม่เปิดแอปใหม่เมื่อดาวน์โหลดหรือติดตั้งล้มเหลว
- `src/components/UpdateScreen.test.tsx`: แสดงเวอร์ชันและไบต์ที่รับ เปอร์เซ็นต์และ progressbar เข้าถึงได้ สถานะไม่ทราบขนาดไม่มีค่าความคืบหน้าปลอม แยกสามขั้น จัด focus ป้องกัน Escape ปิดหน้าติดตั้ง และมีข้อความครบสามภาษา
- `src/App.updates.test.tsx`: เปิดหน้าจอจาก Settings ติดตั้งได้ครั้งเดียวเมื่อกดซ้ำ รับสถานะจาก callback จริงของตัวช่วยอัปเดต กลับสู่หน้าข้อผิดพลาดที่ลองใหม่ได้ และไม่ให้ผลตรวจตอนเปิดแอปที่มาช้าเขียนทับการติดตั้งที่เริ่มไปแล้ว

## ตรวจภาพและการเข้าถึง

- ตรวจธีมสว่างและมืด หน้าต่าง 1280×800 และขนาดเล็ก ตัวอักษรและความคืบหน้าอ่านชัด กรณีสูงไม่พอเลื่อนภายในการ์ดได้
- ตรวจไทย อังกฤษ และญี่ปุ่น ชื่อเวอร์ชันยาวไม่ดันหน้าจอออกด้านข้าง
- ขณะ modal เปิด Tab ต้องไม่ออกไปเมนูหรือปุ่มด้านหลัง Escape ไม่ปิดกระบวนการติดตั้ง เมื่อเกิดข้อผิดพลาดต้องกลับไปตรวจหาอัปเดตได้
- เมื่อเปิด Reduce motion แถบรอไม่เคลื่อนไหว แต่สถานะข้อความยังอัปเดตตามจริง

## ด้วยมือบนแอป Windows จริง

- [ ] ติดตั้งรุ่นที่มีหน้าจอนี้ แล้วตรวจหารุ่นที่ใหม่กว่าจริง เลือกอัปเดตและตรวจเวอร์ชันเป้าหมาย
- [ ] ระหว่างดาวน์โหลดแสดงไบต์และเปอร์เซ็นต์ที่ได้รับจาก updater ไม่มีตัวเลขเวลาเหลือที่เดาเอง
- [ ] ถ้าเซิร์ฟเวอร์ไม่แจ้งขนาดไฟล์ แสดงแถบรอโดยไม่มีเปอร์เซ็นต์ จนดาวน์โหลดจบ
- [ ] ดาวน์โหลดจบเปลี่ยนข้อความเป็นเตรียม/ติดตั้ง จากนั้นตัวติดตั้ง Windows ปิดแอปตามพฤติกรรมของ updater และเปิดรุ่นใหม่ได้
- [ ] ตรวจเลขเวอร์ชันใหม่ การตั้งค่า เพลง และประวัติฝึกหลังเปิดใหม่
- [ ] ทดสอบขาดอินเทอร์เน็ตหรือแพ็กเกจไม่ถูกต้องในสภาพแวดล้อมทดสอบ ต้องแจ้งข้อผิดพลาด ไม่เปิดใหม่เอง และตรวจหาอัปเดตเพื่อลองใหม่ได้ ห้ามเปลี่ยนกุญแจหรือลดการตรวจลายเซ็นเพื่อทดสอบ

หน้าจอไม่แสดงเปอร์เซ็นต์ระหว่างติดตั้ง เพราะ updater ไม่รายงานความคืบหน้าช่วงนี้ บน Windows แอปเดิมอาจปิดทันทีเมื่อตัวติดตั้งเริ่ม จึงอาจไม่เห็นขั้นเปิดใหม่ในหน้าต่างเดิม
