## ด้วยมือบนเครื่องจริง (ยังไม่ได้ทำ)

ทำในแอปที่หน้า **เสียงและ MIDI** แล้วบันทึกชื่ออุปกรณ์และผลของแต่ละข้อ

- [ ] Windows 11 เห็น USB MIDI input จาก Badger C-918 (บันทึกชื่อที่แสดง)
- [ ] กด C4 แล้วได้ pitch 60 ทั้ง 3 ครั้ง พร้อม note off
- [ ] กดคอร์ด C–E–G แล้วได้ 3 note on
- [ ] กดเบาและแรงแล้ว velocity ต่างกัน (ถ้าเครื่องรองรับ)
- [ ] เหยียบ pedal แล้วได้ CC64 (ถ้ามี pedal)
- [ ] ถอดและเสียบ USB ตอนไม่ได้เล่น แล้วเชื่อมต่อใหม่ได้ ไม่มีโน้ตค้าง
- [ ] เสียงเปียโนออกทางลำโพงหรือหูฟังคอมพิวเตอร์ (Phase 1)
- [ ] โหลด Salamander Grand Piano V3 (.sfz) แล้วจดเวลาโหลดและ RAM ที่ใช้ (Task Manager) เล่นคอร์ดหนักๆ พร้อม pedal แล้วเสียงไม่แตก ไม่กระตุก
- [ ] หน้าเปียโนอิสระ: เลือก "ดังเท่ากันทุกโน้ต" แล้วกดเบาและแรงได้ยินเท่ากัน, เปิดเสียงก้องแล้วไม่มีเสียงแตกหรือ latency เพิ่ม
- [ ] เปียโน, metronome และเพลงประกอบเล่นพร้อมกันได้ ไม่มีเสียงแตก (Phase 1–4)
- [ ] วัด latency จริงและบันทึกแยกตามอุปกรณ์ (Phase 1)

บันทึกผลแต่ละข้อพร้อมวันที่และเวอร์ชันแอปลงใน issue หรือไฟล์นี้
- [ ] ทำบท "หาโน้ต C ถึง G" และ "คอร์ด C – G – Am – F" จากเปียโนจริงจนจบ ผลต้องไม่ติดป้ายว่าจำลอง

## ตรวจหน้า "วันนี้" และการเริ่มฝึก

- ผู้ใช้ใหม่: ผลสะสมเป็นศูนย์และแนะนำบทแรก กดเริ่มแล้วเปิดบทนั้นโดยตรง
- จบบทด้วยคีย์บอร์ดจำลอง: จำนวนรอบจำลองเพิ่ม แต่ดาวและจำนวนบทที่จบด้วยเปียโนจริงไม่เพิ่ม ยังแนะนำบทเดิม
- จบบทด้วย MIDI จริง: กลับหน้า "วันนี้" แล้วผลสะสมอัปเดต เมื่อความแม่นโน้ตดีที่สุดต่ำกว่า 85% แนะนำทบทวนก่อน เมื่อถึง 85% จึงแนะนำบทถัดไป (ทุกบทยังเปิดได้)
- จบครบทุกบท: แนะนำทบทวนบทที่ความแม่นโน้ตดีที่สุดยังต่ำกว่าบทอื่น โดยไม่นำคะแนนจำลองมาคิด
- ปุ่มแผนฝึกเปิดเปียโนอิสระ บทแนะนำ แกะโน้ต และแผนบทเรียนได้ครบทั้งสามภาษา
- เวลา 5/10/10/5 นาทีเป็นคำแนะนำ ต้องไม่แสดงว่าเป็นเวลาที่ฝึกไปแล้ว และยังไม่ถือว่าภารกิจรายวันเสร็จ
- เทสต์ตรรกะ: `src/features/lessons/today.test.ts` ครอบคลุมผู้ใช้ใหม่ รอบจำลอง รุ่นบทเรียนเก่า ผลนอกหลักสูตร และการทบทวน

## ตรวจธีมกลางคืน

- เลือกธีมมืดในตั้งค่า พื้นหลักต้องดำสนิท การ์ดเทาเข้ม ข้อความอ่านชัด โลโก้ ปุ่ม ดาว และโน้ตไม่มีสีอื่น
- เปียโนอิสระ: คีย์ขาวเป็นขาว คีย์ดำมีขอบชัด เมื่อกดคีย์พื้นเป็นเทาและมีกรอบ ชื่อโน้ตยังอ่านได้ คีย์บอร์ดอยู่ก่อนชุดปรับเสียง
- บทเรียน: โน้ตเป้าหมายมีแถบล่าง กดค้างตรงเป้าหมายต้องมีทั้งสีพื้นและกรอบแยกจากคีย์ที่ยังไม่ได้กด ตรวจทั้งคีย์ขาวและคีย์ดำ
- แกะโน้ต: โน้ตที่เลือกมีกรอบเส้นประ หัวโน้ตกลวงยังแยกจากตัวดำได้ เส้นตำแหน่งใส่และเส้นเล่นฟังยังต่างรูปแบบ
- เปิดแอปใหม่ยังจำธีมที่เลือก สลับกลับธีมสว่างได้ และตรวจซ้ำบนจอจริงในห้องมืดโดยปรับความสว่างจอตามสบาย
- เทสต์ `src/styles/night.test.ts` ตรวจค่าพาเลตและคอนทราสต์ ส่วนความสบายตาและเสียง/MIDI จริงยังต้องทดสอบบนเครื่องเจ้าของ

## ตรวจแกะโน้ตด้วย MIDI และเล่นวน

- เปิดเพลงที่มีโน้ต แล้วเริ่มฝึกด้วย MIDI จริง เมื่อกลับมาเพลงต้องไม่ถูกเพิ่มหรือเปลี่ยนโน้ตจากการฝึก
- เปิดฟังเพลงแล้วเล่น MIDI ตาม เสียงเปียโนจริงยังเล่นได้ แต่ต้องไม่เพิ่มโน้ตลงเพลงระหว่างฟัง
- ใส่คอร์ดสามเสียงพร้อมกัน ต้องเริ่มที่จังหวะเดียวกัน เล่นทำนองประจุดต่อกันต้องไม่ย้อนทับโน้ตก่อนหน้า
- ใส่เขบ็ตสองชั้นประจุด แล้วบันทึก/เปิดใหม่ ต้องแสดงจุดและความยาวเดิม
- เลือกวนที่ห้องท้าย แล้วลบห้องว่างท้ายเพลง ช่วงวนต้องอยู่ในจำนวนห้องที่เหลือ
- ฟังสองมือที่มี pitch ซ้อนกัน ต้องไม่ปล่อยเสียงก่อนทุกโน้ตจบ เปลี่ยนเพลง/มือ/ช่วง/ความเร็วระหว่างฟังต้องหยุดรอบเดิม
- จบรอบหรือกดหยุด ต้องไม่มีโน้ตจากการฟังค้างอยู่

## ตรวจประสบการณ์บทเรียน v0.4.0

- ก่อนกดเริ่ม: ลอง MIDI/คีย์บนจอได้ แต่ยังไม่มีรอบฝึกหรือคะแนนเพิ่ม กดเริ่มแล้วนับจากโน้ตแรก
- ปิดตัวช่วย: ชื่อโน้ต/เลขนิ้วและคีย์เป้าหมายหายไป แต่บรรทัดโน้ตและการตัดสินโน้ตยังเหมือนเดิม
- ฝึก 3 บทวลีแรก: ทำนองและเบสที่ฝึกแยกต้องตรงกับบทสองมือ ปล่อยแล้วกดใหม่ทุกขั้น รวมโน้ตเดิมซ้ำ
- จบด้วยคีย์บนจอหรือผสม MIDI: ต้องติดป้ายจำลอง ไม่เพิ่มดาวหรือจำนวนบทที่จบบนเปียโน คำแนะนำไม่อ้างว่าพร้อมจากคะแนนจำลอง
- สถานะ MIDI ในวันนี้/บทเรียน: ไม่เชื่อมต่อ รอเครื่อง เชื่อมต่อ และข้อผิดพลาดต้องตรงกับ backend ไม่อ้างความสามารถที่ยังไม่ทดสอบ
- ถอด MIDI กลางคอร์ดแล้วเสียบใหม่: ต้องกดโน้ตให้ครบใหม่ ไม่มีโน้ตจากก่อนถอดช่วยผ่านขั้น
- ย้อนกลับเมนูฝึกซ้อมต้องเปิดแผนบทเรียน เลื่อนขึ้นต้นหน้าและรับโฟกัส ไม่ค้างในบทเดิม
- ประวัติจากรุ่นเดิม: 12 บทเดิมและดาวยังอยู่ 3 บทใหม่เริ่มจากศูนย์
- ปิดแล้วเปิดแอป: ธีม ภาษา เสียง และผลฝึกยังอยู่ ถ้า storage เขียนไม่สำเร็จต้องแจ้งว่าเก็บผลไม่สำเร็จ
- ตรวจ 1024×640 และขยายหน้าต่าง ข้อความไทย/อังกฤษ/ญี่ปุ่นไม่ล้นขอบ ปุ่มใช้งานด้วย Tab/Enter/Space ได้ และการลดการเคลื่อนไหวทำงาน

เทสต์อัตโนมัติครอบคลุมตรรกะและเหตุการณ์ MIDI จำลอง การตรวจเสียง/latency/ความสบายตาจริงยังต้องทำบนเครื่องและเปียโนของเจ้าของ ไม่ถือว่าทดสอบฮาร์ดแวร์แล้วจากพรีวิวเบราว์เซอร์

## โปรแกรมฝึกแบบโฟกัส

- เล่นเพลงโน้ตตก: ตรวจตำแหน่งแถบตรงกับคีย์ที่เส้นรับโน้ต ปรับความเร็ว/พัก/เล่นต่อ/เริ่มใหม่ และจบเพลงได้จริง เสียงตัวอย่างต้องหยุดเมื่อพัก/ออก/สลับหน้าต่าง/reset MIDI ไม่มีคะแนนหรือประวัติปลอม แหล่งเพลงดู FREE_SONGS.md

- ตรวจตาม `docs/DRILL_TEST_PLAN.md` ทั้งชื่อโน้ต ภาพบรรทัด 5 เส้น และคอร์ดจริง
- เริ่มจาก Today/ฝึกซ้อม เมนูต้องซ่อนตอนเล่น ปุ่มพักและ Escape ใช้ได้ ปิดคีย์จำลองแล้วเหลือโจทย์เท่านั้น
- จับคอร์ดต้องครบ ไม่มีโน้ตเกินค้าง ก่อนโจทย์ใหม่ต้องปล่อยคีย์ รอบที่ใช้คีย์บนจอแม้เพียงบางส่วนติดป้ายจำลอง
- MIDI reset กลางคอร์ดต้องพักและล้างคีย์ค้าง เมื่อกลับมาฝึกต้องกดคอร์ดครบใหม่ เสียง/คีย์ไม่ค้างเมื่อออกหรือสลับหน้าต่าง
- ภาพแนะนำนิ้วต้องตรง C, G/B, Am และ F/A ตาม voicing ที่แสดง แอปตรวจได้เฉพาะโน้ต ไม่รับรองการใช้นิ้ว/ท่ามือจาก MIDI
- กราฟเทียบเฉพาะแบบทดสอบที่จบ อ้างอิงเวอร์ชัน/โจทย์/ช่วง/จำนวนเดียวกัน และแยกเปียโนจริงกับจำลอง ไม่ใช้จำนวนรอบเป็นคะแนนความคล่อง
