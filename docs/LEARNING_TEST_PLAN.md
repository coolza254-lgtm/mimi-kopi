# เมนูเรียนและแบบฝึกท้ายบท

หลักสูตรเริ่มต้น 4 บท: คีย์ C–G, อ่านกุญแจซอล C4–G4, อ่านกุญแจฟา C3–G3 และคอร์ดมือขวา C, G/B, Am เปิดเลือกและกลับมาทบทวนได้ทุกบท

## หลักการสอน

- เขียนคำอธิบายใหม่เป็นภาษาง่าย ใช้คีย์ดำเป็นตำแหน่งอ้างอิง จากภาพ → กดคีย์ → ผลตอบสนอง → ไปขั้นถัดไป ไม่คัดลอกข้อความ/รูป/โน้ต/การจัดหน้าของหลักสูตรอื่น
- สอนครั้งละเรื่อง C D E F G; เส้นและช่องสลับกัน; จุดอ้างอิง C4/E4/G4 และ C3/F3; ชื่อกุญแจไม่ใช่คำสั่งตายตัวว่ามือไหนต้องเล่น
- แบบฝึกท้ายบท 12 ข้อใช้เฉพาะ target ที่สอนในบทนั้น ต้องกดถูกครบทุกข้อจึงบันทึกจบ กดผิดลองใหม่ได้ จำนวน 12 เป็นขนาดรอบ ไม่ใช่เกณฑ์วิจัยหรือการรับรองความคล่อง ไม่มีคะแนนจังหวะ
- บันทึกวันจบแยกจริง/จำลองใน `mimi-kopi.learning.v1` ไม่ขึ้นกับประวัติฝึก 200 รอบ บทที่อ่านหรือทดลองกลางทางยังไม่ถือว่าจบ หากบันทึกล้มเหลวต้องแสดงข้อผิดพลาด
- ภาพนิ้วในบทคอร์ดรวมกับคีย์ที่เล่นได้ชุดเดียว คีย์จำลองคอร์ดใช้แตะกดค้าง/แตะซ้ำปล่อย เพื่อกดหลายคีย์ด้วยเมาส์ได้ ส่วน MIDI จริงยังใช้การกดคีย์จริงตามปกติ พัก/reset/ออกหน้าต้องล้างคีย์จำลอง
- ภาพนิ้วเป็นคำแนะนำสำหรับ voicing ที่ระบุ MIDI ตรวจนิ้วไม่ได้ บทเรียนนี้ยังไม่ครอบคลุมค่าตัวโน้ต จังหวะ ตัวหยุด เครื่องหมายแปลงเสียง หรือการประสานสองมือเต็มหลักสูตร

ตรวจข้อเท็จจริงเรื่องตำแหน่งกุญแจและโน้ตจากผู้สอนต้นทาง [Hoffman Academy: Bass Staff Basics](https://app.hoffmanacademy.com/lessons/piano/bass-staff-basics/video/) และ [Sight Reading in the Treble and Bass Clef](https://app.hoffmanacademy.com/lessons/piano/sight-reading-in-the-treble-and-bass-clef/video/) ส่วนเลขนิ้วอ้างอิง [Yamaha](https://hub.yamaha.com/keyboards/k-how-to/the-basics-of-piano-keyboard-fingering/) ใช้เฉพาะข้อเท็จจริงพื้นฐาน ไม่ใช้สื่อของแหล่งเหล่านั้น

## ตรวจอัตโนมัติ

- course.test.ts: แบบฝึกมีเฉพาะโน้ตที่สอน ทุก target ถูกถาม ไม่มีโจทย์ซ้ำติดกัน แยก reference จากโปรแกรมซ้อม จบจริงก่อนบันทึก แยกผลจำลอง รักษาวันจบเมื่อประวัติรอบถูกตัด และรับมือ storage เสีย/เต็ม
- Learn.test.tsx: กดผิดไม่ปลดปุ่มถัดไป กดถูกแล้วไปทีละขั้น ไม่มีประวัติจบก่อนทำแบบฝึกครบ จบรอบแล้วแสดงจำลองถูกต้อง ออกกลางทางไม่จบ MIDI คอร์ดต้องครบ reset ล้างโน้ตค้างและถอน listener เมื่อออก
- ReadingStaff.test.tsx: C4 มีเส้นน้อย E4 อยู่เส้นล่างสุด C3 อยู่ช่องถูกต้อง และจุดกุญแจฟาคร่อม F3

## ตรวจหน้าจอและเครื่องจริง

1. ขนาด 1024×640 ทั้งสามภาษาและสองธีม ภาพ/คำอธิบาย/คีย์/ปุ่มไปต่อไม่บังกัน อ่านบทได้โดยไม่เห็นเฉลยในแบบฝึกท้ายบท
2. ขณะสอนมีคำอธิบายสั้นและภาพช่วย ขณะแบบฝึกซ่อนเมนูและเฉลยเหมือนโปรแกรมฝึก ปุ่มพัก/Escape/กลับใช้งานได้
3. ทดลองบนจอแล้วแสดงจำลอง ต้องไม่เพิ่มจำนวนบทที่จบด้วยเปียโนจริง เปิดใหม่แล้วยังจำวันจบ
4. เจ้าของลอง MIDI จริงทุกบท โดยเฉพาะ G/B กับ Am และท่ามือที่สบาย ไม่อ้างผ่านจากผลเบราว์เซอร์
5. เพลงโน้ตตกแยกซ้ายเขียว/ขวาน้ำเงินทั้งสองธีม มี L/R เพิ่ม เลือกทีละมือแล้วไม่เหลือแถบอีกมือ คีย์ที่แนะนำใช้สีตรงกับมือ
