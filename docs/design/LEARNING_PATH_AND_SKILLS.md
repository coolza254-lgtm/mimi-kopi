**ปรับหลังตรวจหลักฐาน 2026-10-28:** ใช้ [ผลทบทวนและข้อกำหนดที่แก้แล้ว](LEARNING_EVIDENCE_REVIEW.md) ควบคู่เอกสารนี้ เมื่อรายละเอียดการสอน/ประเมินต่างกัน ให้ใช้ฉบับทบทวนนี้เป็นข้อกำหนดล่าสุด หกช่วงเป็นแผนที่หัวข้อที่ยังต้องทดลอง ไม่ใช่หลักสูตรที่พิสูจน์ประสิทธิผลแล้ว

## โครงหน้า

- **เส้นทางเรียน** เป็นหน้าหลักสำหรับเรียน มีลำดับที่แนะนำ เป้าหมายสั้น และบทถัดไปที่อธิบายเหตุผลได้ ย้อนทบทวนหรือเลือกข้ามได้ ไม่ใช้หัวใจ XP หรือลงโทษเมื่อขาดวัน
- **ทักษะของฉัน** แยกการเรียนจบจากผลประเมิน บอกขอบเขตการทดสอบและข้อมูลที่ยังไม่พอ ไม่สรุปเป็นเลเวลหรือเรดาร์ความสามารถรวม
- **ฝึก** คงใช้ฝึกซ้ำเฉพาะจุด ปรับความเข้มข้นได้ เชื่อมจากบทเรียนหรือข้อที่พลาด ไม่บังคับให้เลือกจากรายการแบบฝึกที่ไม่มีบริบท
- **เล่นเพลง/แกะโน้ต** เป็นจุดนำทักษะไปใช้ ไม่ถือว่าเปิดหรือเล่นเพลงจบแล้วพิสูจน์ว่ามีทักษะนั้น

ในต้นแบบแสดงเฉพาะสามหน้าที่กำลังออกแบบ ไม่ใช่ข้อเสนอให้ลบเมนูอื่น การฝึกจริงยังซ่อนเมนู เหลือโจทย์ใหญ่ พัก และผลตอบสนองเบา ๆ ตามความต้องการเดิม

## ลำดับหลักสูตรที่เสนอ

| ช่วง | เป้าหมาย | มีแล้วใน 0.5.1 | ต้องเพิ่ม |
|---|---|---|---|
| รู้จักคีย์และเสียง | เชื่อมเสียงกับคีย์ C–G | บทคีย์และหาโน้ต | ฟังทิศทางสูง/ต่ำ/เท่าเดิม |
| อ่านทำนองและจังหวะ | อ่านแล้วเล่นวลีสั้น | ซอล C4–G4 และโจทย์อ่านทีละตัว | ค่าตัวโน้ต ตัวหยุด pulse วลี และการประเมินต่อเนื่อง |
| รู้จักมือซ้าย | อ่านเบสและใช้มือซ้าย | ฟา C3–G3 | การนำไปใช้กับเบสเพลงและทักษะมือซ้ายโดยเฉพาะ |
| จับและเปลี่ยนคอร์ด | จับถูกและเปลี่ยนอย่างผ่อนคลาย | C, G/B, Am ภาพนิ้ว และโจทย์คอร์ด | สอนการเปลี่ยนต่อเนื่อง จังหวะ และฟังคุณภาพคอร์ดภายหลัง |
| เล่นสองมือเป็นเพลง | รวมทำนองกับเบส | โน้ตตกเลือกมือได้ | บทแยกมือ/รวมมือ และการประเมินรายท่อน |
| แกะเพลงด้วยตัวเอง | ฟังแล้วเล่นวลีใหม่ | เครื่องมือแกะโน้ตด้วยตนเอง | หลักสูตรฟังแล้วเล่นตาม และแบบประเมินด้วยวลีใหม่ |

ทุกช่วงใช้วงจร **เข้าใจ → ซ้อมแก้จุดติด → ลองเองโดยลดตัวช่วย → วลีใหม่ → ใช้กับเพลง → ทวนหลังเว้นช่วง** แทรกการฟัง จังหวะ และเพลงง่ายตั้งแต่ต้น ไม่ต้องรอถึงช่วงสุดท้ายจึงได้ฝึกฟังหรือเล่นเพลง แบ่งช่วงเป็นบทเล็กก่อนพัฒนา ไม่ทำหกหัวข้อใหญ่เป็นบทเดียว

การเรียนจบหมายถึงทำขั้นเรียนและท้ายบทครบ ไม่ใช่ความคล่อง เกณฑ์เลื่อนทักษะต้องกำหนดจากโจทย์ใหม่ที่ครอบคลุมสิ่งที่สอนและการทดสอบซ้ำคนละวัน ยังไม่กำหนดเปอร์เซ็นต์หรือจำนวนวันที่อ้างว่าเป็นมาตรฐาน งานออกแบบนี้ไม่ได้ผ่านการรับรองหลักสูตรโดยครูเปียโน

## ข้อมูลจริงที่มีและข้อจำกัด

- `drill-history.v1`: ชนิดแบบฝึก ระดับ จำนวนข้อ โหมด key อ้างอิง วันที่ แหล่งจริง/จำลอง ตอบถูกครั้งแรก จำนวนกดผิด รายโจทย์ และรอบที่ยังไม่จบ เก็บล่าสุด 200 รอบ
- `learning.v1`: วันจบบทแยกจริง/จำลอง คงอยู่แม้ประวัติ 200 รอบหมุนออก มี 4 บทในปัจจุบัน
- `mimi-kopi.lessons`: 15 บทเดิมมีผลต่อเวอร์ชัน จำนวนรอบจริง/จำลอง best accuracy และ best duration ต้องแสดงเป็นประวัติบทเดิม ไม่ปนกับ benchmark ใหม่ และเวลาของโหมดรอไม่ใช่คะแนนจังหวะ
- ปัจจุบันยังไม่มีข้อมูลประเมินหู จังหวะ ความคล่องในการอ่าน การใช้สองมือ หรือผลเล่นเพลง การกดคีย์ MIDI ไม่บอกนิ้ว/ท่ามือ/ความผ่อนคลาย

ข้อเสนอหน้าทักษะ: แสดงผลประเมินล่าสุดที่จบแล้วแยกหาโน้ต/อ่านโน้ต/คอร์ด ใช้ **ถูกครั้งแรก x/y ข้อ** พร้อมวันที่ ช่วงเสียง จำนวนข้อ รุ่นแบบประเมิน และแหล่งรับคีย์ กดดูข้อพลาดและประวัติได้ แสดงการอ่านแยกซอล/ฟาได้เฉพาะเมื่อ key หรือ metadata ระบุขอบเขตได้จริง ไม่เดาจาก level เพียงอย่างเดียว

แนวโน้มเทียบเฉพาะ key ของแบบประเมินคงที่เดียวกันและแหล่งเดียวกัน ไม่ปนรอบสุ่มซ้อม รอบไม่จบ หรือคนละจำนวนข้อ/เวอร์ชัน และติดป้ายว่าเป็นผลชุดเดิม ไม่ใช่การอ่านโจทย์ใหม่ เพิ่มส่วนวลีใหม่และทวนหลังเว้นช่วงแยกเมื่อมีหลักฐานจริง โดยไม่ถือว่าคนละ form ยากเท่ากันอัตโนมัติ ผลจริงเป็นค่าเริ่มต้น มีตัวเลือกผลจำลองแยกชัดเจน ถ้าไม่มีผลให้บอกว่า **ยังไม่ประเมิน** ถ้าอ่านข้อมูลไม่ได้ให้บอกว่า **โหลดผลไม่ได้** ไม่ใช้ 0 แทนทั้งสองกรณี ไม่เรียกจำนวนรอบใน rolling history ว่าตลอดชีวิต

ก่อนพัฒนาต้องออกแบบ migration ของ Today ที่ยังอ้างอิง 15 บทเดิมให้ไม่ขัดกับเส้นทางใหม่ รักษาประวัติเดิมทั้งหมด ไม่ตั้งบทที่เคยจบกลับเป็นใหม่ และไม่แปลงผลจำลองเป็นจริง

## การฝึกฟัง

แนะนำให้มี เพราะเป้าหมายเจ้าของคือฟังแล้วแกะทำนอง/คอร์ด ข้อเสนอนี้เน้นความสัมพันธ์ของเสียงและฟังแล้วเล่นตาม เริ่มสั้น ๆ แทรกในบท ไม่เน้นทายชื่อเสียงโดด ๆ โดยไม่มีเสียงตั้งต้น

1. สูงขึ้น/ต่ำลง/เท่าเดิม ใช้เสียงง่าย ฟังซ้ำได้
2. ให้เสียงตั้งต้น ฟัง 2–3 โน้ต แล้วเล่นตาม ค่อยขยายช่วงและความยาว
3. วลีทำนองใหม่ แบ่งท่อน ลองกด ฟังเทียบ เปิดเฉลยเมื่อขอ
4. เสียงเบสและคุณภาพคอร์ดเมื่อพร้อม แล้วนำไปใช้กับเพลง

แยกโหมดสอนที่ให้ฟัง/เฉลยได้ออกจากโหมดประเมิน ต้องเก็บว่าฟังซ้ำหรือใช้คำใบ้หรือไม่ ก่อนอ้างผลฟังโดยไม่ช่วย ไม่ต้องใช้ไมโครโฟนในระยะแรก ใช้ MIDI ตอบและเสียงสร้างเองโดยไม่บันเดิลเพลงหรือเสียงที่ไม่มีสิทธิ์ใช้

ABRSM อธิบายความสำคัญของการฟังต่อ pitch ความจำดนตรี จังหวะและการสังเกตข้อผิดพลาด พร้อมตัวอย่างฟัง/ร้องวลี/ตบจังหวะ: https://teacherhub.abrsm.org/mod/page/view.php?id=2020

RCM รวม aural skills กับการอ่านและการเล่นตามทำนอง/จังหวะใน musicianship: https://www.rcmusic.com/learning/certificate-program-faqs

ลำดับด้านบนเป็นข้อเสนอที่ปรับให้เข้ากับแอปนี้ ไม่ใช่การคัดลอกหลักสูตรสอบหรือคำรับรองผลการเรียน

## ลำดับพัฒนาหลังตกลงแบบ

1. กำหนด rubric/blueprint และ metadata การประเมินให้แยกชุดเดิม วลีใหม่ ตัวช่วย และทวนหลังเว้นช่วง ก่อนสร้างตัวสรุปหลักฐานแบบ pure function พร้อมเทสต์ขอบเขต key/แหล่งจริงจำลอง/ข้อมูลว่างเสียหาย/rolling history และหน้าทักษะสามภาษา
2. จัดเส้นทางจากบทที่มีแล้ว เชื่อม Today/ฝึก/ทบทวนโดยรักษาประวัติและแยกสถานะเนื้อหาที่ยังไม่มี เพิ่มจังหวะและวลีสั้นต้นหลักสูตร ไม่เลื่อนไว้หลังทำ dashboard ครบ
3. เพิ่มหน่วยฝึกฟังที่เชื่อมไปถึงฟังแล้วเล่นตาม พร้อมเสียงที่สร้างเอง การหยุดเสียงเมื่อพัก/ออก/เบลอ และทดสอบการรับ MIDI/คำใบ้/ผลประเมิน แยกการทายสูงต่ำจากทักษะแกะทำนอง
4. เพิ่มโหมดต่อเนื่องและตรวจ timeline/อุปกรณ์ก่อนให้คะแนนจังหวะ ทดลองนำร่อง/ทวน/วลีใหม่ตามเอกสารทบทวน แล้วค่อยขยายสองมือ ไม่ใช้จบบทหรือจำนวนรอบเป็น mastery
5. ตรวจตาม AGENTS ทุกชิ้น push ดู CI เขียวและอัปเดต Handoff; Release ตาม RELEASING.md เมื่อ implementation พร้อม ไม่ออก release สำหรับต้นแบบเอกสารนี้
