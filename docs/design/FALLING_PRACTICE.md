# ฝึกโน้ตตก 0.9.0

เข้าจากแกะโน้ต → เลือกเพลง → ฝึกโน้ตตก เปิดทั้งเพลงตามห้องสุดท้ายที่มีโน้ต ปุ่มท้าย editor เปิดเฉพาะช่วงที่เลือก หน้าตั้งค่าปรับช่วงห้องและความเร็วได้ มือใช้ตัวเลือกเดิมใน editor

เวทีซ่อนเมนูรอบข้าง เหลือชื่อเพลง กลับ พัก โจทย์ใหญ่ เวลา และคีย์เปียโนขาว โน้ตซ้ายเขียว/ขวาน้ำเงินทั้งสองธีม สีบอกมือจึงคงอยู่ในธีมขาวดำ ใช้ canvas วางแท่งตรงกับตำแหน่งคีย์ ไม่โหลดภาพหรือเพลงภายนอก

โหมดรอหยุดที่ onset จนคีย์ครบคอร์ด ไม่มีคีย์ผิดค้างในหน้าต่างตอบ คีย์เดิมต้องปล่อยและกดใหม่สำหรับโน้ตซ้ำ ตอบถูกเดินต่อเอง ไม่ประเมินจังหวะหรือความยาวที่ถือ การกดคีย์บนจอล็อกคีย์ให้ตอบคอร์ดด้วยเมาส์ได้ กดซ้ำเพื่อปล่อย และปล่อยอัตโนมัติหลังตอบครบ

โหมดฟังเดินตามเวลาไฟล์และส่งเสียง guide ไม่รับเป็นคำตอบหรือผลฝึก ในเว็บเป็นเสียงสังเคราะห์เบา ๆ ที่ผู้ใช้เริ่มเอง ในแอปใช้เครื่องดนตรีที่ตั้งไว้ ไม่มีเสียงปุ่ม

ระบบลดการเคลื่อนไหวตาม OS เป็นค่าเริ่มต้น เลือกเปิดการเคลื่อนโน้ตเองได้ ข้อความโจทย์อยู่เหนือ canvas เสมอ จอ 1024×640 แสดงคีย์ครบโดยไม่เลื่อน พักเมื่อสลับหน้าต่างหรือระบบเสียง/MIDI ขัดข้อง

บันทึกเฉพาะรอบรอที่จบ ใช้ประวัติเดิม มีเพียงจำนวนรอบ actual accuracy/durationMs เป็น null ไม่ใช้เป็นหลักฐานผ่านบทพื้นฐานหรือระดับทักษะ การใช้จอแม้ผสมเปียโนจริงยังนับจำลอง ออกจากรอบกลางทางไม่บันทึกและไม่กู้ตำแหน่ง รอบฟังไม่บันทึก

ข้อจำกัด: ยังไม่ประเมิน pedal/จังหวะ/การถือโน้ต และยังไม่ได้ทดสอบอุปกรณ์จริง ไม่ใช้ browser เป็นหลักฐาน hardware
