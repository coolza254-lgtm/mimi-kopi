# สตูดิโอชุดใหม่ — 0.8.0

เจ้าของขอออกแบบทั้งระบบใหม่และไม่ชอบเสียงเอฟเฟกต์ของ0.7.1 จึงนำเสียงดังกล่าวออกทั้งหมด ใช้การเคลื่อนไหวสั้นแทน ยังคงธีมขาวชมพูและขาวดำ ไม่เพิ่มโลโก้ ชื่อแอป หรือคำบรรยายที่เคยขอนำออก

- ภาษาภาพ: พื้นคล้ายกระดาษ ปุ่มสีหมึก พื้นปกชมพู และตัวอักษรไทยน้ำหนักชัด ใช้ฟอนต์บันเดิลเดิม ทุกสีเปลี่ยนเป็นขาว/ดำ/เทาในธีมขาวดำโดยไม่ใช้ filter ครอบทั้งแอป
- เมนู: ชื่อเต็มกับไอคอนในแถบซ้าย ตำแหน่งเลือกชัด การย่อเป็นไอคอนยังมี accessible name และ tooltip
- หน้าแรก: เรื่องที่เริ่มได้ทันทีเป็นปกหลัก คู่ข้อมูลจบบทจริงและกิจกรรมที่บันทึกจริง เครื่องมือส่วนตัวอยู่ด้านล่าง ภาพเปียโนSVGเป็นภาพตกแต่งที่สร้างเอง ไม่ใช่เพลงหรือการแสดงผลการเล่น
- เส้นทาง: ตาราง8หัวข้อแยกบทชัด รายละเอียดและปุ่มเริ่มอยู่ข้างกัน ทุกบทเปิดได้ตามระบบเดิม ไม่มีล็อกหรือXPเพิ่ม
- ทักษะ: แยกเปียโนจริง/จำลองชัด แผงผลแสดงข้อมูลจากประวัติจริง หากยังไม่ประเมินให้แสดงตามนั้น ไม่วาดกราฟความสามารถสมมติ
- บทเรียน/โจทย์: พื้นที่คงที่ในviewport ข้อความหรือภาพโจทย์เข้าใน200–280ms คีย์บอร์ดไม่เคลื่อนไหว ถูกแล้วเดินต่อเอง ผิดให้ทบทวนในที่ที่เตรียมไว้ ปิดการเคลื่อนไหวเมื่อใช้ reduced motion
- เครื่องมือ: โปรแกรมฝึก ผลรอบ เปียโนอิสระ แกะโน้ต เสียง/MIDI ตั้งค่า และหน้าดาวน์โหลดใช้รูปทรงปุ่ม ช่องกรอก และพื้นผิวเดียวกัน คีย์ขาวยังขาว ปรับแผงเสียงในเปียโนอิสระให้เลื่อนในพื้นที่ของตนเองเพื่อเก็บพื้นที่คีย์บอร์ด
- เนื้อหา: ย่อและพับคำอธิบายเพิ่มเติม เช่นสำรองเพลง แต่ข้อผิดพลาดการอ่าน/บันทึก และแหล่งข้อมูลจริง/จำลองต้องปรากฏชัด

`atelier.css` เป็นชั้นภาพรวมที่โหลดสุดท้าย ส่วน`interaction.css`รักษาขนาดพื้นที่ฝึก CSSเครื่องมือเดิมคุมgeometryและพฤติกรรมเฉพาะ เลิกimportชุดexpression/tools-expression/palettesเก่าและภาพisometricเดิม ไม่มีการเปลี่ยนเกณฑ์ประเมินหรือschemaเพลง/ผลฝึก

ตรวจทุกหน้าหลัก สองธีม ภาษาไทย/อังกฤษ/ญี่ปุ่น ขนาด1024×640 การเดินวลีจริงแบบจำลอง และการเข้าถึงด้วยคีย์บอร์ดก่อนRelease การผ่านCIไม่ยืนยันเสียง/MIDIหรือความคล่องจากการเรียนจริง
