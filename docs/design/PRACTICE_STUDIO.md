# ห้องซ้อม Mimi Kopi

## เป้าหมาย

ช่วยผู้เริ่มต้นฝึกวันละประมาณ 30 นาทีเพื่อค่อย ๆ เล่นเพลงที่ชอบ อ่านโน้ตและประสานสองมือได้ โดยไม่สร้างแรงกดดันหรืออ้างความสามารถเกินผลที่วัดจริง

## ภาพและการใช้งาน

- ธีมสว่างใช้ขาวอุ่นและกราไฟต์ แต้มชมพูหม่นเฉพาะจุดสำคัญ ธีมกลางคืนเป็นดำ เทา ขาว คีย์เปียโนยังขาวและดำตามเครื่องดนตรีจริง
- ลำดับข้อมูล: สิ่งที่ควรทำต่อ → เหตุผลสั้น ๆ → ปุ่มหลักหนึ่งจุด → รายละเอียดที่เปิดดูเพิ่มได้ แสดงเฉพาะเมนูที่ใช้งานได้
- tokens.css กำหนดสี ระยะ ฟอนต์ และรัศมี studio.css จัดหน้ารวม ส่วน night.css โหลดท้ายเพื่อคุมขาวดำและคีย์เปียโน
- ฟอนต์ Noto Sans Thai Variable รวมในแอป ไม่เรียกเครือข่าย เก็บ SIL OFL ที่ public/licenses/NotoSansThai-OFL.txt ไอคอนและภาพประกอบเป็น SVG ต้นฉบับ ไม่คัดลอกหน้าจอผลิตภัณฑ์อื่น
- รองรับ Tab/Enter/Space มี skip link คืนโฟกัส/เลื่อนต้นหน้าเมื่อเปลี่ยนพื้นที่ และลดการเคลื่อนไหวตามระบบ เป้าหมายเปียโนใช้แถบล่าง กดอยู่ใช้สีพื้นและกรอบ จึงไม่พึ่งสีอย่างเดียว
- เปียโนอิสระแสดงการเล่น ตามด้วยคีย์บอร์ดเต็มแถว แล้วจึงเป็นชุดปรับเสียง เพื่อลดการเลื่อนผ่านพื้นที่ว่าง

## เส้นทางการฝึก

15 บทใน 5 หมวด: คีย์บอร์ด → มือขวา → มือซ้าย → คอร์ด → วลีต้นฉบับ ทำนองและเบสในวลีแยกมือตรงกับบทสองมือ เพื่อใช้วิธีเดียวกันกับท่อนเพลงของผู้ใช้เอง

ก่อนเริ่มมีวิธีวางมือ โฟกัส และการนำไปใช้กับเพลง อุ่นมือได้โดยไม่เก็บคะแนน เมื่อคุ้นแล้วปิดชื่อโน้ต/เลขนิ้ว/เป้าหมายบนคีย์เพื่ออ่านบรรทัดโน้ต โดยไม่เปลี่ยนตรรกะคะแนน

แนะนำทบทวนเมื่อความแม่นโน้ตดีที่สุดบนเปียโนยังต่ำกว่า 85% แต่ทุกบทเปิดได้เสมอ ผลหลังจบแยกการจำลองออกจากเปียโนจริง คะแนนจังหวะไม่มีในโหมดรอ เวลาไม่ใช้จัดอันดับหรือแนะนำความพร้อม บทเดิมทั้ง 12 บทคง id/version/โน้ตเพื่อเก็บประวัติ

## ขอบเขตการตรวจ

ตรวจ DOM และภาพครบทุกหน้า ทั้งสามภาษา สว่าง/มืด ขนาดต่ำสุด 1024×640 และหน้าต่างแคบ ตรวจจบบทจำลอง การคืนโฟกัส สถานะ MIDI ที่เปลี่ยนระหว่างรอ และความล้มเหลวในการบันทึกด้วยเทสต์ แผนทดสอบฮาร์ดแวร์อยู่ใน docs/MIDI_AUDIO_TEST_PLAN.md

ยังไม่รวมโหมดต่อเนื่อง metronome คะแนนจังหวะ SQLite หรือนำเข้าไฟล์ MIDI ซึ่งเป็นงานระบบใน roadmap รอบถัดไป
