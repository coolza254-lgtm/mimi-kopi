# Design references

หน้าจอทั้งหมดออกแบบครั้งแรกใน Artifact canvas ของเจ้าของ ("耳コピー Mimi Kopi UI Design")
แล้วคัดลอกมาไว้ที่นี่ (snapshot วันที่ 2026-10-25) เพื่อให้ agent ทุกตัวเห็นแบบเดียวกัน

## ไฟล์

- `screens/*.dc.html`: แบบของแต่ละหน้า หนึ่งไฟล์ต่อหนึ่งหน้า ชื่อหน้าอยู่ใน `screens/canvas.json` (`boards.<file>.title`)
  - เปิดในเบราว์เซอร์ตรง ๆ จะไม่สวยเพราะต้องใช้ runtime ของ canvas (`support.js`) ให้อ่าน HTML/CSS แทน
  - สี ระยะ และตัวอักษรอยู่ใน `<style>` ของแต่ละไฟล์ ตรงกับ `src/styles/tokens.css`
  - รูปโลโก้ (`/_blob/...`) อยู่ใน canvas เท่านั้น ในแอปใช้ `src/assets/brand-mark.png`
  - ข้อความในแบบหลายจุดเป็น "ข้อมูลตัวอย่าง" ห้ามนำตัวเลขตัวอย่างไปแสดงเป็นผลจริง (spec §2.2)
- `prototypes/note-editor-prototype.html`: ต้นแบบเครื่องมือแกะโน้ตแบบไฟล์เดียว (เปิดในเบราว์เซอร์ได้เลย)

## ใช้อย่างไร

- **แบบเป็นแนวทาง ไม่ใช่สเปก** ถ้าแบบขัดกับ `docs/PRODUCT_SPEC.md` ให้ยึดสเปก
- แอปจริงอาจต่างจากแบบได้เมื่อทำแล้วใช้งานดีกว่า (เช่น หน้า ฝึกซ้อม และ เปียโนอิสระ ในแอปออกแบบใหม่ระหว่างเขียนโค้ด)
- **ถ้าเจ้าของสั่งแก้ดีไซน์ผ่าน agent ที่ไม่มีเครื่องมือ Artifact (เช่น Codex)** ให้แก้ไฟล์ใน `screens/` หรือแก้โค้ดของแอปโดยตรง แล้วบันทึกใน `docs/HANDOFF.md`
  ว่าแก้อะไร เพราะ canvas บน claude.ai จะไม่อัปเดตตาม ครั้งหน้าที่กลับมาใช้ canvas ต้องคัดลอกจากที่นี่กลับขึ้นไป
