# Design references

- หน้าจอทั้งหมดออกแบบไว้ใน Artifact canvas ของเจ้าของ ("耳コピー Mimi Kopi UI Design") ถ้าเจ้าของส่งภาพหรือ HTML ของหน้าจอมาใส่ในโฟลเดอร์นี้ ให้ยึดตามนั้น
- `prototypes/note-editor-prototype.html`: ต้นแบบเครื่องมือแกะโน้ตแบบไฟล์เดียว (เปิดในเบราว์เซอร์ได้เลย) ที่ทำไว้ก่อนเริ่มโปรเจกต์นี้ คลิกวางโน้ตบนบรรทัดและลากได้
  ใช้เป็นแนวทางตอนทำหน้า "แกะโน้ต" ในแอปจริง (ดู `docs/HANDOFF.md`) ไม่ต้องคงโค้ดนี้ไว้ตามเดิม
