ความสามารถสถานะวิธีตรวจ
USB MIDI endpointยังไม่ทดสอบรายการอุปกรณ์ MIDI
Note on / offยังไม่ทดสอบกด C4
Velocityไม่ทราบกดเบาและแรง
Sustain (CC64)ไม่ทราบเหยียบ pedal
Polyphony (คอร์ด)ยังไม่ทดสอบกด 3 โน้ต
