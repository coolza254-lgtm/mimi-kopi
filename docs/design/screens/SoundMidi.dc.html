อินพุต MIDI

ไม่พบอุปกรณ์

ชื่ออุปกรณ์จะแสดงที่นี่เมื่อ Windows มองเห็น USB MIDI endpoint ของเปียโน · ยังไม่ยืนยันกับ Badger C-918

ความสามารถที่ตรวจพบ

Note on / offยังไม่ทดสอบ หลายโน้ตพร้อมกัน (คอร์ด)ยังไม่ทดสอบ Velocityยังไม่ทราบ Sustain (CC64)ยังไม่ทราบ

สถานะ: รองรับ / ไม่รองรับ / ยังไม่ทดสอบ · ไม่สรุปความสามารถก่อนทดสอบจริง
