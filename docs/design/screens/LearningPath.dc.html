ขั้น A · สัปดาห์ 1–4

ยังไม่เริ่ม
  • อ่านชื่อโน้ตและตำแหน่งคีย์
  • โน้ต landmark บน treble/bass
  • ทำนองสั้น 2–4 ห้อง, 5-finger
  • triad เมเจอร์/ไมเนอร์พื้นฐาน
เกณฑ์ผ่าน: เล่นทำนองสั้นและแบบฝึกจังหวะผ่านเกณฑ์ที่ตั้งไว้

ขั้น B · สัปดาห์ 5–8

ล็อกไว้
  • โน้ตกว้างขึ้น, rest, eighth note
  • สลับคอร์ดและ broken chord
  • แยกมือ → สองมือสั้น ๆ
  • แบ่งท่อนเพลงเป็น fragment
เกณฑ์ผ่าน: ท่อน 4–8 ห้องแบบง่ายที่ BPM ที่กำหนด

ขั้น C · เดือน 3–6

ล็อกไว้
  • อ่านโน้ตเพิ่ม ลดการพึ่ง falling notes
  • สองมือ, accompaniment pattern
  • แผนเพลง A / B / ฮุก / บริดจ์
  • ฟังแกะวลี 2–4 โน้ต
เกณฑ์ผ่าน: หนึ่ง section ของเพลงเป้าหมายเล่นคล่องแบบ simplified

ขั้น D · เดือน 6–12

ล็อกไว้
  • ต่อหลาย section เป็นเพลงเต็ม (ฉบับง่าย)
  • transition, ความต่อเนื่อง, dynamics
  • inversion และ harmony awareness
เกณฑ์ผ่าน: เล่นเพลงหนึ่งเพลงจบตาม arrangement ที่ตกลงกัน

ขั้น E · ระยะยาว

ล็อกไว้
  • บันทึกไอเดียทำนองด้วยหู
  • หา root movement จากเสียงที่ฟัง
  • transpose, voicing, pattern ballad/pop/bossa
  • สร้าง arrangement ของตัวเองใน portfolio
เกณฑ์ผ่าน: มี arrangement ที่คุณสร้างเองอย่างน้อยหนึ่งชิ้น
