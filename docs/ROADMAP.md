# Roadmap

อ้างอิงจาก `docs/PRODUCT_SPEC.md` §13 ทุกเฟสต้องมี working demo และเกณฑ์ผ่านก่อนไปเฟสถัดไป

| เฟส | เนื้อหา | ด่าน (gate) |
|---|---|---|
| 0 | โครงโปรเจกต์ เอกสาร design tokens test plan Git baseline | build และเปิดแอปเปล่าได้บน Windows 11 |
| 1 | MIDI + เสียง vertical slice (P0) | กดคีย์ Badger C-918 แล้วเห็น pitch ถูกต้องและได้ยินเสียง ถ้าไม่รองรับให้ใช้ simulator ได้ แต่ไม่ผ่านด่านฮาร์ดแวร์ |
| 2 | แบบฝึกพื้นฐาน + scoring ที่ตรวจได้ (P0/P1) | ฝึก 30 นาทีได้จริง บันทึกและดูย้อนหลังได้ unit test ครอบคลุมกรณีสำคัญ |
| 3 | Song Studio: นำเข้า MIDI ที่มีสิทธิ์ใช้ และวนท่อน (P1) | นำเข้า 4 ห้อง วนฝึก และบันทึก section accuracy ได้ถูกต้อง |
| 4 | Ear Copy workspace (P1) | นำเข้าเสียง วนช่วง บันทึก MIDI attempt โดยไม่รายงาน accuracy ปลอม |
| 5 | Adaptive coaching, MusicXML, analytics (P2) | แผนวันถัดไปเปลี่ยนได้อธิบายจาก weakness จริง |
| 6 | Arrangement Lab, ความเสถียร, installer และระบบอัปเดต (P2) | installer ผ่านการทดสอบ upgrade และไม่สูญเสียข้อมูลการฝึก |

## สถานะปัจจุบัน

- Phase 0: เสร็จ (build บน Windows ผ่าน CI)
- Phase 1: เขียนโค้ดแล้ว ผ่าน CI แต่**ยังไม่ผ่านด่านฮาร์ดแวร์** ต้องทดสอบกับ Badger C-918 ตาม `docs/MIDI_AUDIO_TEST_PLAN.md`
- Phase 2: มีบทเรียนพื้นฐาน 15 บทใน 5 หมวดในโหมดรอ บันทึกผลในเครื่อง (localStorage) เปียโนอิสระ และหน้า "วันนี้" แนะนำบทจากผลจริงพร้อมแผนฝึกประมาณ 30 นาทีแล้ว (เวลาแนะนำ ยังไม่มีจับเวลาหรือประวัติรายวัน) ยังไม่มีโหมดต่อเนื่อง metronome การให้คะแนนจังหวะ และ SQLite
- อัปเดตในแอป (เดิม Phase 6): ทำแล้วตั้งแต่ 0.2.0 ตามคำขอของเจ้าของ
- หน้าอัปเดต: มีหน้าดาวน์โหลด/ติดตั้ง/เปิดใหม่พร้อมความคืบหน้าจริงทั้งธีมสว่างและมืด ไม่เดาเปอร์เซ็นต์เมื่อไม่มีขนาดไฟล์ และแสดงข้อผิดพลาดพร้อมทางลองใหม่ มีเทสต์ lifecycle และหน้าจอ
- ธีมกลางคืน: ปรับธีมมืดเป็นดำ/เทา/ขาว รวมคีย์เปียโน บรรทัดโน้ต และสถานะเลือก มีเทสต์คอนทราสต์ของข้อความและคีย์ คีย์เปียโนกลับเป็นขาวตามปกติตามคำขอเจ้าของแล้ว
- UX/UI: หน้าวันนี้และเมนูใหม่ ฟอนต์ไทยออฟไลน์ เตรียมมือก่อนเริ่ม ซ่อนตัวช่วยอ่านโน้ต คำแนะนำตามผลจริง และสถานะ MIDI มีเทสต์ DOM/ตรรกะและตรวจภาพ 3 ภาษาแล้ว ดู `docs/design/PRACTICE_STUDIO.md`
- เครื่องมือแกะโน้ต: มีตัวแก้ไข ฟัง/วนท่อน/ฝึกแบบรอ และสำรอง/นำเข้าผ่าน JSON แล้ว ยังไม่มีตัวหยุด เส้นโยง beam และไฟล์ MIDI
- ความเสถียรแกะโน้ต: แยกการรับ MIDI ออกจากช่วงฝึก/ฟังแล้ว รองรับเขบ็ตสองชั้นประจุดและโน้ตค้างข้ามขอบเขตช่วงที่ฟัง พร้อมเทสต์ UI และเทสต์อ่านเขียนไฟล์ Windows ใน CI
- Phase 3: มีตัวแก้ไขเพลงและวนท่อนเบื้องต้นแล้ว ยังไม่ผ่านด่านนำเข้า MIDI และผลรายท่อน ส่วน Phase 4 และหลังจากนั้นยังไม่เริ่ม
