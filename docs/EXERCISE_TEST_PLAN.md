# เส้นทางเรียน ทักษะ และชุดฝึกฟัง/วลี

## หน้าจอคงที่และผลตอบ 0.7.1 — 2026-10-31

- วัดกรอบบทเรียน/คีย์บอร์ด/ปุ่มท้ายหน้าก่อนตอบ หลังผิด หลังถูก และข้อถัดไป ที่ viewport เดียวกันต้องเท่าเดิม รวมคำอธิบายยาว ภาษาไทย/อังกฤษ/ญี่ปุ่น และ 1024×640
- บทสอนต้องกดครบและปล่อยคีย์ทุกตัวก่อน timer 900ms เริ่ม ข้อสุดท้ายเปิดหน้าเตรียมท้ายบท ไม่ผ่านบททันที; blur/reset ยกเลิกการเดินต่อและเสียง
- แบบฝึกวลีต้องปล่อยคีย์ก่อน feedback 700ms รวมข้อสุดท้ายไปหน้าผลเอง พักช่วง feedback แล้วกลับมาต่อได้โดยไม่บันทึกซ้ำ ไม่มี auto-play โจทย์เสียงใหม่
- ผิดแล้ว review ค้าง ไม่รับคำตอบใหม่/ไม่เดินข้อ พร้อมเฉลยความต่างที่เกิดจริง กดลองใหม่จึงตอบได้ จำนวนผิดเดิมไม่หาย วลีเริ่มต้นใหม่และเก็บการใช้ตัวช่วยเมื่อเฉลยเปิดแล้ว จับโน้ตค้างจาก MIDI ต้องปล่อยก่อนตอบซ้ำ
- งดเสียงเอฟเฟกต์ในโจทย์ฟัง direction/melody ทั้งคลิกและถูกผิด คีย์เปียโนไม่เกิดเสียงปุ่มซ้ำ ตรวจ mute/reduced motion/focus และการเปิดข้อมูลรุ่นเดิมได้

## เพิ่มเติมชุดเริ่มเรียนและความปลอดภัยข้อมูล 2026-10-29

- ดีไซน์ล่าสุด: ขาวชมพู/ขาวดำแทน minimalเดิม ตรวจข้อความสั้น/รายละเอียดที่พับได้/การเปลี่ยนธีม/เอฟเฟก hover-press และ reduced motion คงค่าการตั้งค่า light/dark เดิมเพื่อไม่เปลี่ยนข้อมูลเก่า สีขาวดำต้องเป็นneutralทั้งภาพและหน้ารอง คีย์ขาวเหมือนเปียโนจริง

- Today เปิดบท/แบบฝึกที่แนะนำโดยตรง พร้อมโหมดและจำนวนข้อ 3/6; ไม่ต้องเลือกบทเดิมซ้ำ หน้าหลักอธิบายเหตุผลจากรอบที่ใช้จริง เปิดดูแหล่ง/วันเวลา/ผลได้
- คำแนะนำเป็นกฎนำทางที่ยังไม่ได้พิสูจน์ผลการเรียน: รอบล่าสุดยังไม่จบแนะนำเริ่มรอบใหม่ (ไม่อ้างว่ากู้รอบเดิม), มีผิดแนะนำซ้อม, ซ้อมครบไม่ผิดแนะนำลองเอง, จากนั้นบทที่ยังไม่เคยทำครบ เมื่อแนะนำครบจึงเสนอทวนตามเวลาที่สังเกตจริงหรืออ่านวลี ไม่อ้างช่วงทวนที่เหมาะที่สุด
- การจบบท/แบบฝึกที่จำลองช่วยนำทางได้ แต่ไม่ได้กลายเป็นผลเปียโนจริง กิจกรรมวันนี้นับเฉพาะรอบฟัง/วลีที่จบตามวันในเครื่อง แยกจริง/จำลอง ไม่ใช่เวลาฝึกหรือคะแนนทักษะ
- Path/Skills เปิดฝึกตรงช่วงหลักฐาน: keyboard/treble C4–G4, bass C3–G3, chords C · G/B · Am; key ของซ้อมแยกจากท้ายบท ห้ามบันทึกจบบทหรือเทียบเป็นผลประเมิน
- หลังตอบถูกและปล่อยคีย์ ข้อถัดไปเปิดหลัง feedback 700ms; คำถามฟังยังต้องกดฟังเอง ข้อสุดท้ายให้เปิดผลเอง พัก/blur/Escape/ออกหน้าต้องยกเลิก timer และกลับมาที่ feedback เดิมได้โดยไม่นับซ้ำ
- โฟกัสหลังตอบถูกอยู่ปุ่มถัดไป/ดูผล ไม่ค้างบนปุ่มที่ถอดออกจาก DOM; ทดสอบคีย์บอร์ดและ reduced motion ทั้งสองธีมที่ 1024×640
- จบรอบแล้วมีทางต่อที่ทำงานจริง: มีข้อผิดแนะนำซ้อมเรื่องเดิมพร้อมตัวช่วย 3 ข้อ; ซ้อมครบไม่ผิดมีปุ่มลองเอง 3 ข้อ เริ่มรอบใหม่แยก ID/โหมด เก็บผลเดิม ไม่อ้างว่าเป็นการฝึกเฉพาะวลีที่พลาดหรือข้ามระดับเพราะจบรอบ รายโจทย์อยู่ในรายละเอียด และคอลัมน์เปิดเสียงมีเฉพาะเรื่องฟัง
- โหลดประวัติ drill/learning/legacy เสียแม้เพียง record เดียวต้องแยกจากไม่มีผล ไม่กรองทิ้ง/normalize แล้วบันทึกทับ raw; จบรอบใหม่ต้องแจ้งบันทึกไม่ได้และไม่อ้างสถิติสูงสุด ลองโหลดใหม่ได้
- เพลงส่วนตัวผิดรูปแบบ/มี schema ไม่รู้จัก/โน้ตถูกตัดทิ้งจะไม่เข้า editor และไม่ autosave ทับ มีสำรอง raw; เมื่อเขียนไม่ได้ระหว่างแก้เพลง ต้องลองใหม่/ส่งออกงานในหน่วยความจำได้ และไม่เพิ่มผลฝึกในหน่วยความจำเสมือนบันทึกสำเร็จ
- จำนวนเปิดเสียงเป็นการขอเปิด รวมการเล่นที่ล้มเหลวหรือถูกพักกลางทางด้วย เพื่อไม่อ้างว่าผู้เรียนได้ยินครั้งเดียวโดยไม่ทราบแน่ชัด ผลลองเองที่ต้องเปิดใหม่จึงถูกนับอย่างระมัดระวัง ไม่ใช่ตัววัดการฟังจบ

ใช้ตรวจรุ่น 0.6.0 ทั้งเว็บจำลองและแอป Windows จริง ผลเว็บไม่ใช่ผลทดสอบเปียโนของเจ้าของ

## ขอบเขตและข้อมูล

- เส้นทาง 8 จุด: คีย์ → ฟังสูงต่ำ → ค่าตัวโน้ต → ซอล → อ่านวลี → ฟังแล้วเล่นตาม → ฟา → คอร์ด แนะนำจุดแรกที่ยังไม่มีรอบจบ ไม่อ้างความคล่อง ย้อนหรือข้ามได้ บทเดิม 4 บท/ประวัติ 15 บทยังอยู่
- ชุดใหม่เลือกซ้อม/ลองเองและ 3/6/12/24 ข้อ ซ้อมเริ่มคีย์ขาวซ้ำ/ติดกัน ลองเองใช้ C4–G4 เสียง/วลีสร้างเอง ไม่ใช้เพลงตัวอย่างหรือเนื้อหาจากบทความวิจัย
- `mimi-kopi.exercises.v1` เก็บประวัติล่าสุด 200 รอบ แยกจากพจนานุกรมเคยเปิดซึ่งไม่หมุนออกตามประวัติ เก็บชนิด โหมด จำนวน วันเวลา จริง/จำลอง จำนวนพัก และรายข้อ: form ID, ผิด, จำนวนฟัง, ตัวช่วย, เคยเปิด/ไม่เคย/ไม่ทราบ และทำเสร็จหรือยัง
- เก็บ exposure ก่อนเปิดวลี/เล่นเสียง รวมรอบที่ออกกลางทาง ผลใหม่หมายถึงยังไม่เปิดในข้อมูลเครื่องนี้ ไม่ยืนยันว่าไม่เคยได้ยินที่อื่น และคนละ form ไม่ถือว่ายากเท่ากัน
- ผลทำเองครั้งแรกต้องไม่ผิด ไม่ใช้ตัวช่วย และโจทย์ฟังเปิดครั้งเดียว ผลซ้อมรายงานถูกครั้งแรกของการซ้อมแยก ไม่ให้ผู้เรียนได้ 0 เพียงเพราะเลือกซ้อมพร้อมตัวช่วย
- ทวนหลังเว้นช่วงแสดงวลีเดิมของรอบลองเองที่จบและแหล่งเดียวกัน หลังห่างอย่างน้อย 24 ชั่วโมง บอกจำนวนวันจริง ไม่อ้างว่าไม่ได้ซ้อมระหว่างนั้น

## จุดตรวจ

1. วันนี้ → เรียนต่อ ไปเส้นทาง เลือกเปิดทุกบทได้ครบไทย/อังกฤษ/ญี่ปุ่น ไม่มีเมนู/เพลงตัวอย่าง เครื่องมือแกะโน้ตและเพลงส่วนตัวไม่เปลี่ยน
2. หน้าทักษะเริ่มแหล่งจริง เปลี่ยนเป็นจำลองแล้วเห็นเฉพาะผลจำลอง ไม่รวมแบบฝึกคนละ key/ช่วง/จำนวน/รุ่น หรือรอบสุ่ม/ไม่จบ การจบบทแยกจากผลชุดเดิม ไม่มีระดับความสามารถรวมปลอม
3. ข้อมูลว่างแสดงยังไม่ประเมิน ข้อมูลเสีย/สิทธิ์ storage ไม่พอแสดงโหลดหรือบันทึกไม่ได้ ไม่เขียนทับข้อมูลเสียเป็นค่าว่าง
4. อ่านวลี: C4 อยู่เส้นเสริม E4 เส้นล่าง G4 เส้นที่สอง ช่วง C4–G4 โน้ตตัวดำ 3 ตัว ไม่มีชื่อเฉลยในโหมดลองเอง กดค้างไม่ตอบโน้ตซ้ำ กดหลายคีย์ไม่ถูกนับเป็นเมโลดี้ ต้องปล่อยก่อนกดถัดไป
5. ฟัง: สูง/ต่ำ/เท่าเดิมคาดเดาลำดับไม่ได้ เปลี่ยนเสียงตั้งต้นในช่วงสอน เล่นเสียงจบก่อนตอบ เสียง guide ผ่าน midiSimulate ไม่เป็นคำตอบหรือเปลี่ยนรอบ MIDI เป็นจำลองเอง
6. ฟังแล้วเล่น: ตอบ MIDI/คีย์จำลองได้ แยกแหล่งทั้งรอบ ฟังซ้ำและเปิดชื่อโน้ตมีบันทึก ไม่ถูกนับเป็นผลทำเองครั้งแรก การกดผิดยังอยู่เมื่อพัก/ฟังซ้ำ
7. ค่าตัวโน้ต: รูปตัวดำ/ตัวขาว/ตัวกลมชัดทั้งสองธีม อธิบายว่าบทนี้นับตัวดำเป็น 1 จังหวะ มีตัวอย่างก่อนเริ่ม ตอบ 1/2/4 ผิดแล้วแก้ได้ ผลเป็นความเข้าใจบนจอ ไม่ใช่จังหวะการเล่น
8. พัก/Escape/สลับหน้าต่าง/ถอด MIDI หยุดเสียง ล้างคีย์ หยุดนับคำตอบ note-on ที่มาถึงช้าหลังออกมี note-off ไม่มี timer/listener ค้าง เปลี่ยนการแสดงคีย์จำลองได้ขณะพัก
9. ออกกลางรอบยังมีผลบางส่วน ปิดเปิดแล้วอยู่ จำนวนฟัง/ตัวช่วย/ผิดตรงกับการเล่น ประวัติหมุนออกเมื่อครบ 200 แต่เคยเปิดยังอยู่
10. ตรวจสองธีม/สามภาษา/1024×640 โจทย์ คีย์ ปุ่มพักและผลไม่ล้น โฟกัสคีย์บอร์ดอยู่เนื้อหาที่เห็น ซ่อนเมนูระหว่างฝึก และเสียงล้มเหลวต้องไม่เปิดให้ตอบราวกับฟังสำเร็จ

## ข้อจำกัด

ยังไม่ประเมินจังหวะการเล่น ความเร็วอ่าน นิ้ว สองมือ หรือแกะเพลงเต็ม และยังไม่มีผลการศึกษาประสิทธิผลกับเจ้าของ ต้องขยายค่าตัวโน้ตในวลี/โหมดต่อเนื่องและเนื้อหาหลังพื้นฐานภายหลัง โดยไม่แปลงผลรุ่นนี้เป็นผลของทักษะใหม่
