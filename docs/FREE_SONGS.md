# เพลงพื้นฐานที่แจกไปกับแอป

ตรวจแหล่งที่มา 2026-10-26 เฉพาะทำนองที่เป็นสาธารณสมบัติ ไม่ใช้เนื้อร้อง เสียงบันทึก MIDI รูปโน้ต หรือฉบับเรียบเรียงสมัยใหม่จากแหล่งภายนอก ข้อมูล pitch/จังหวะใน `src/features/songs/catalog.ts` ใส่ใหม่เป็นทำนองมือขวาใน C major และเสียงต่ำมือซ้ายเสริม ลดรายละเอียดเพื่อให้เล่นง่าย ไม่ใช่ฉบับเต็มสำหรับการแสดง

| เพลง | ที่มาทำนองที่ตรวจ | ฉบับในแอป |
| --- | --- | --- |
| Twinkle, Twinkle, Little Star | ทำนองฝรั่งเศส Ah! vous dirai-je, maman ใช้ในงานของ Mozart; [Mutopia](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=2236) ระบุ Public Domain และแหล่งพิมพ์เก่า Paris: Porro | ทำนองหลัก C4–A4 ไม่มี variation หรือคู่กีตาร์ของฉบับในแหล่งอ้างอิง |
| Frère Jacques | [IMSLP](https://imslp.org/wiki/Fr%C3%A8re_Jacques_(Rameau,_Jean-Philippe)) ระบุต้นฉบับราว 1772 F-Pn MS-1843 เป็น Public Domain และการระบุผู้แต่ง Rameau เป็นเพียง attribution | เมโลดี้เดี่ยว G3–A4 ไม่ทำ canon และไม่ใช้ฉบับเรียบเรียงปี 2025 |
| Ode to Joy | ทำนองหลักของ Symphony No.9, Op.125, Beethoven; [ต้นฉบับปี 1824 และฉบับพิมพ์ครั้งแรกปี 1826](https://imslp.org/wiki/Symphony_No.9_(Beethoven,_Ludwig_van)) ระบุ Public Domain | ท่อนหลักย้ายเป็น C major เสียงเดียว G3–G4 ไม่ใช้ orchestration/ฉบับเรียบเรียง/เสียงบันทึกบนหน้านั้น |

หน้าเลือกเพลงเปิดดูแหล่งทำนองได้ เพลงพร้อมใช้แบบ offline ไม่ต้องดาวน์โหลดไฟล์จากเว็บ เสียงตัวอย่างในแอปสร้างจากเครื่องเสียงเดิมที่ผู้ใช้เลือก ไม่มี sample ใหม่แนบไปด้วย เพิ่มเสียงต่ำมือซ้ายแบบ root note ที่ทำขึ้นใหม่สำหรับฝึกสองมือ เลือกเฉพาะซ้าย/ขวา/สองมือได้ แถบซ้ายเขียว ขวาน้ำเงิน และตัวอักษร L/R ไม่ใช้สีเพียงอย่างเดียวบอกมือ

โหมดโน้ตตกเป็นการเล่นตามเวลาเพื่อความเพลิดเพลิน ไม่มีคะแนน ไม่มีการบันทึกผลการฝึก ไม่อ้างการอ่านโน้ตคล่องหรือการทดสอบฮาร์ดแวร์ เสียงตัวอย่างและคีย์บนจอใช้ MIDI จำลอง ส่วนโปรแกรมฝึกยังแยกผลจำลองจาก MIDI จริงตามเดิม

ก่อนเพิ่มเพลงใหม่ต้องตรวจ **ทำนองต้นฉบับ** แยกจากลิขสิทธิ์เสียงบันทึกและฉบับเรียบเรียง ห้ามถือว่าเพลงที่ฟังฟรีบนเว็บแจกต่อได้
